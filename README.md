# OnlineShop ASP.NET Core 8

An e-commerce project built with ASP.NET Core MVC and Clean Architecture.

## Technologies

- ASP.NET Core 9 MVC
- Entity Framework Core 9
- SQL Server
- C#
- Razor Views
- Bootstrap
- Dependency Injection
- Repository Pattern
- Clean Architecture
- Cookie Authentication
- Role-Based Authorization

## Features

- User registration
- User login/logout
- Password hashing
- Remember Me authentication
- Profile management
- User Management
- Admin Panel
- CRUD Operations
