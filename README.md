# OnlineShop ASP.NET Core 8

An e-commerce project built with ASP.NET Core MVC and Clean Architecture.

## Technologies

- ASP.NET Core 8 MVC
- Entity Framework Core
- SQL Server
- Clean Architecture
- Repository Pattern
- Dependency Injection
- Bootstrap

- User Registration
- Password Hashing
- User Management
- Admin Panel
- CRUD Operations
